# Eventify – Event Management Website

### About the Project
Eventify is an event management website developed as a Web Development college assignment. It provides a platform where users can explore events, view event details and manage their event registrations.

### Features
- Attractive home page
- Browse upcoming events
- Event details
- Event registration
- My Registrations page
- About Us page
- Contact Us page
- Responsive user interface

### Technologies Used
- HTML
- CSS
- JavaScript

### Project Structure
- `index.html` – Home page
- `events.html` – Events listing
- `event-details.html` – Event information
- `my-registrations.html` – Registration details
- `about.html` – About page
- `contact.html` – Contact page
- `css/` – Stylesheets
- `js/` – JavaScript files
- `src/` – Project assets

### How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website.

### Project Objective
The objective of this project is to apply HTML, CSS and JavaScript concepts to develop a functional and user-friendly Event Management Website.

**Developed as a Web Development Assignment.**
